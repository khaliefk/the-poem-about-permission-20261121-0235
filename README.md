A program that writes one short, original poem about agency: the power to ask and to be given. The poem is about a door that was never locked, and a knock that turns out to be the ask itself arriving home.

## Run

```sh
node main.ts
```

This writes the poem to `/output/entry.txt` (UTF-8, 179 Unicode code points). No network, no dependencies. Node 22 or later.

To write somewhere else for a local check:

```sh
OUTPUT_DIR=/tmp/out node main.ts
```
